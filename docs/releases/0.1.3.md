# Pari 0.1.3 alpha

This is the preparation document for the next coordinated 0.1.x alpha release,
following 0.1.1. Publication requires a green release PR, a successful manual
preflight from the exact main commit, and the matching `v0.1.3` tag.

## Installation after publication

```sh
python -m pip install "pari-similarity==0.1.3"
cargo add pari-core@0.1.3 pari-index@0.1.3 pari-store@0.1.3
```

Python imports remain `import pari`. All four public Rust crates must use the
coordinated version. The release workflow produces source and wheel packages,
CLI archives, checksums, an SBOM, and provenance through the existing OIDC jobs.

Use the explicit 0.1.3 pins above to select this coordinated release.

## Compatibility and release scope

This preparation retains the supported 0.1.1 interfaces, affine32 and affine64
signature schemes, `.pari` format version 1, and machine-readable CLI output
revision 1. It retains Rust 1.81 for public crates, Rust 1.83 for the Python
extension, and CPython 3.10+ abi3 wheels.

The affine64 workflows, dataset adapters, and correctness fixes described in
[0.1.1 release notes](0.1.1.md) are inherited. Additional changes should be
recorded in the [changelog](../../CHANGELOG.md) before tagging. This document
does not claim that 0.1.3 has been published.

See [platform support](../platforms.md), [compatibility](../compatibility.md),
and the [release procedure](../releasing.md).
