# Pari 0.1.3 alpha

This draft prepares the next coordinated patch release. Publication remains on
hold while pre-release review finishes; the version has not been published.

## Fixes

- Dataset adapters reject boolean, fractional, and invalid batch sizes before
  importing optional libraries or reading a source.
- Explicit invalid backend values no longer silently select memory storage.
- Code-corpus verification rechecks cached sources and validates every retained
  source snapshot before publishing outputs. Changed inputs roll back staged
  results and the owned persistent index.
- Checksummed benchmark evidence retains its original bytes across Windows and
  Unix checkouts; automatic fixers preserve archived results.

The dedicated native-Linux 10M campaign still requires its documented 128 GiB
host. The out-of-core architecture evaluation remains gated on that evidence.

## Installation after publication

```sh
python -m pip install "pari-similarity==0.1.3"
cargo add pari-core@0.1.3 pari-index@0.1.3 pari-store@0.1.3
```

Python imports remain `import pari`. Keep all four public Rust crates on the
same release version. Supported APIs, affine32/affine64 signature identities,
`.pari` format version 1, and CLI machine-output revision 1 retain their contracts.
Public crates retain Rust 1.81; the Python extension retains Rust 1.83 and
CPython 3.10+ abi3 wheels. Existing [0.1.2 fixes](0.1.2.md) are inherited.

The final release requires green candidate CI, an exact-main manual preflight,
and the matching signed tag under the [release procedure](../releasing.md).
