# Pari 0.1.1 alpha

Pari returns to the 0.1.x alpha line with a coordinated Rust, Python, and CLI
release. This is a new release version. The previously published 0.2.0 packages,
tag, release notes, and checksums retain their original identities.

## Installation and version selection

```sh
python -m pip install "pari-similarity==0.1.1"
cargo add pari-core@0.1.1 pari-index@0.1.1 pari-store@0.1.1
```

Python imports remain `import pari`. Public Rust crates use exact coordinated
inter-crate versions. The CLI reports `pari 0.1.1`.

Because registries compare version numbers, an unpinned installation can select
the historical 0.2.0 release. Pin 0.1.1 explicitly. No existing package is renamed,
deleted, or yanked as part of this correction.

The release workflow builds CPython 3.10+ abi3 wheels and CLI archives for Linux
x86_64, Linux arm64, macOS arm64, and Windows x86_64. Artifacts become available
only after tag validation and publication succeed.

## Included changes

- Explicit affine64 MinHash, LSH, Python, CLI, and persistent-index workflows,
  while affine32 remains the default.
- Bounded-batch deduplication, dataset adapters, exact verification, progress
  reporting, and text, code, and entity-matching examples.
- Fixes for failed Python close operations, closed-handle validation, mutable
  feature buffers, raw-byte hashing, persistent query metrics, atomic output
  publication, Redis retention, and benchmark process cleanup.
- Dependency updates preserve Rust 1.81 for public crates and Rust 1.83 for the
  Python extension. Publication continues through the existing OIDC workflow.
- A shorter README organized around installation and common workflows.

## Compatibility

Supported 0.1.0 and historically published 0.2.0 interfaces remain compatible.
Signature identifiers, `.pari` format version 1, and CLI machine-readable output
revision 1 retain their meanings. Applications should ignore unknown output
fields and verify approximate candidates when exact thresholds matter.

See the [compatibility contract](../compatibility.md),
[platform matrix](../platforms.md), and [changelog](../../CHANGELOG.md).
