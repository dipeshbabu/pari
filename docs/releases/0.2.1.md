# Pari 0.2.1 alpha

Pari 0.2.1 alpha is the complete release of the
[0.2.0 feature set](0.2.0.md): similarity-scored search with stored
signatures, a similarity floor for deduplication, and the `shingles` text
feature helper. There are no code changes from 0.2.0.

## Why 0.2.1

The 0.2.0 tag published the four Rust crates to crates.io, but PyPI rejected
the Python wheels and source distribution because their filenames had been used
by an earlier upload that was later deleted. PyPI never reuses filenames, so
0.2.0 cannot be published for Python. 0.2.1 publishes every package, the CLI
archives, and the GitHub Release together so all versions stay aligned.

## Installation

```sh
python -m pip install "pari-similarity==0.2.1"
cargo add pari-core@0.2.1 pari-index@0.2.1 pari-store@0.2.1
```

Python imports remain `import pari`. Keep all four public Rust crates on the
same release version. Rust users on 0.2.0 can upgrade without code changes.
CLI archives, checksums, and the dependency SBOM are attached to this release
with GitHub build provenance attestations.
