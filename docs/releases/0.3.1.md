# Pari 0.3.1 alpha

Open an existing `.pari` file through Python's `ReadOnlyIndex` or the CLI's
`pari search --read-only` flag. The reader selects the signature width from
the file, skips per-key band hashes used for updates, and loads matching
bucket members on demand. Snapshots with stored signatures support ranked
results, `top_k`, and minimum similarity. See the
[Python guide](../python.md#search-a-read-only-snapshot) and [CLI guide](../cli.md).

Persistent commits also sort bucket memberships within a 128 MiB workspace,
stream metadata sections, and release the previous overlay before reopening
the published snapshot.

The release uses the existing snapshot format. Install the Python package
with `pip install pari-similarity==0.3.1` or download a CLI archive from the
[GitHub release](https://github.com/dipeshbabu/pari/releases/tag/v0.3.1).
