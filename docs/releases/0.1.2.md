# Pari 0.1.2 alpha

Pari 0.1.2 alpha includes output-safety fixes, index validation improvements,
and a hardened publishing pipeline across the coordinated Rust, Python, and CLI release.

## Installation

```sh
python -m pip install "pari-similarity==0.1.2"
cargo add pari-core@0.1.2 pari-index@0.1.2 pari-store@0.1.2
```

Python imports remain `import pari`. Keep the public Rust crates on the same
release version. CLI archives, checksums, and the dependency SBOM are attached
to this release, with GitHub build provenance attestations.

## Fixes

- Human-readable search output escapes control characters in query IDs;
  JSON output preserves the original values.
- Reference workload metrics preserve existing files and linked targets.
  Staged workload outputs must be regular files.
- CLI deduplication preserves source records by rejecting output paths that
  identify the same file, including hard-link and symlink aliases.
- Index verification checks unknown optional section checksums and rejects
  missing, duplicate, and malformed required index metadata.
- Parquet nested column projections retain their nested dictionaries and nulls
  without applying the projection a second time.

## Release hardening

All four Rust crate archives are built and verified together before publication.
The credentialed publishing job uploads those unchanged bytes through the
registry API and verifies their published checksums without running Cargo builds.
Release-tag creation and publication environments have restricted access.
Redis CI and benchmark services use a reviewed, digest-pinned security patch.

## Compatibility

The maintained PyO3 patch preserves the Python extension's Rust 1.83 minimum.
Supported APIs, affine32 and affine64 signature identifiers, `.pari` format
version 1, and CLI output revision 1 retain their contracts. Public Rust crates
remain on Rust 1.81, and Python wheels support CPython 3.10 and newer.

This is an alpha release. See the [compatibility policy](../compatibility.md),
[changelog](../../CHANGELOG.md), and [release procedure](../releasing.md).
