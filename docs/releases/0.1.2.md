# Pari 0.1.2 alpha

This document prepares the next coordinated Rust, Python, and CLI alpha release.
Release versions advance on the 0.1.x line, one patch at a time.

## Installation after publication

```sh
python -m pip install "pari-similarity==0.1.2"
cargo add pari-core@0.1.2 pari-index@0.1.2 pari-store@0.1.2
```

Python imports remain `import pari`. Keep the public Rust crates on the same
release version. Packages and CLI archives are available after the matching
signed tag workflow completes.

## Changes and compatibility

- CLI deduplication preserves source records by rejecting output paths that
  identify the same file, including hard-link and symlink aliases.
- Index verification checks unknown optional section checksums and rejects
  missing, duplicate, and malformed required index metadata.
- Parquet nested column projections retain their nested dictionaries and nulls
  without applying the projection a second time.

The maintained PyO3 patch update preserves the Python extension's Rust 1.83
minimum. CI accepts synchronized patches on the supported dependency line while
rejecting incompatible or mismatched versions.

Supported APIs, affine32 and affine64 signature identifiers, `.pari` format
version 1, and CLI output revision 1 retain their contracts. Public Rust crates
remain on Rust 1.81, and Python wheels support CPython 3.10 and newer.

Before publication, require the complete CI and release matrix and a successful
manual preflight on the exact main commit. See [releasing](../releasing.md),
[compatibility](../compatibility.md), and the [changelog](../../CHANGELOG.md).
